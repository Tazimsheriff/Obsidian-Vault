# 🌌 Obsidian Vault

A personal knowledge management system and dashboard built with Obsidian.

## 📁 Vault Structure

```
obsidian/
├── Dashboard.md                     ← 🏠 Homepage (open this first)
├── 01 - Daily Notes/
│   ├── Template - Daily Note.md     ← Daily log template
│   └── Daily Log.md                 ← Today's note
├── 02 - Tasks/
│   └── Task Tracker.md              ← Master task list
├── 03 - Quotes & Thoughts/
│   └── Quotes Library.md            ← Philosophy & insights
├── 04 - Notes/
│   └── Index.md                     ← Notes index
├── .obsidian/
│   ├── appearance.json              ← Theme config
│   └── snippets/
│       └── dashboard.css            ← Premium dark theme
└── SYNC_GUIDE.md                    ← GitHub sync instructions
```

## 🚀 Getting Started

1. Open Obsidian → **Open folder as vault** → Select this folder (`t:\obsidian`)
2. Go to **Settings → Appearance → CSS Snippets** → Enable `dashboard`
3. Open `Dashboard.md` as your home note (Settings → Core plugins → Slash commands → set homepage)
4. Follow `SYNC_GUIDE.md` to set up GitHub sync on Desktop and Mobile

## 🔄 Sync

This vault is synced via the **Obsidian Git** community plugin.  
See [`SYNC_GUIDE.md`](SYNC_GUIDE.md) for full setup instructions.
